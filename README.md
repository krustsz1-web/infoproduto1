# Landing Page — Salário-Maternidade

Landing page estática para captação de contatos interessados em orientação jurídica sobre salário-maternidade.

## Antes de anunciar
1. Substitua [SEU NOME] e OAB/[UF] [NÚMERO] em index.html.
2. Altere o número do WhatsApp em script.js.
3. Revise os dados profissionais e a política de privacidade.
4. Instale seu domínio no Vercel quando estiver definido.

## Estrutura
- index.html
- style.css
- script.js

A página foi construída sem framework para manter carregamento rápido e implantação simples no Vercel.
